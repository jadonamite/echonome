# General Sans

Designed by Indian Type Foundry, distributed by Fontshare under the ITF Free Font Licence,
which permits commercial use. Files fetched from `cdn.fontshare.com` on 2026-09-09 and
committed here rather than linked, so the site makes no third-party request to render its own
headline and there is no layout shift while a CDN answers.

Chosen because the reference in `design/references/web3-wgmi.jpeg` sets its headline in a wide
geometric grotesque with a double-storey `a`. That rules out Poppins, whose `a` is
single-storey, and General Sans is the closest freely licensed match to the Aeonik-adjacent
face the reference actually uses.

Weights here: 400, 500, 600, 700. Roman only. If an italic is ever needed, fetch it from the
same source rather than letting the browser synthesise a slant.
